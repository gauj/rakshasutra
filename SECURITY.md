# Security

RakshaSutra handles a child's location, so security reports matter more than most.

**Please do not open a public issue for a vulnerability.** Use GitHub's private reporting instead:
Security tab > "Report a vulnerability". Include what you found, how to reproduce it and what it could expose.

We will acknowledge within a few days and fix confirmed issues before discussing them publicly.

Never post real family data, location history, access codes or keys anywhere in this repository, in issues or in pull requests.
